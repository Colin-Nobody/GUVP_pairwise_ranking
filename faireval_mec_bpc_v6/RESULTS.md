# Qwen2.5-VL-7B MEC+BPC V6 结果与限制

正式运行于 2026-08-31 至 2026-09-01 完成。输入为 250 张图片与 3,000 个平衡无序图片对；每对运行两个位置、每个位置三个 MEC 样本。

## 完整性

| 指标 | 结果 |
|---|---:|
| 完成图片对 | 3,000 / 3,000 |
| MEC 方向样本 | 18,000 |
| 有效校准票 | 2,346（78.2%） |
| 校准平局 | 138（4.6%） |
| 严格格式无效对 | 516（17.2%） |
| 单次响应解析失败 | 565 / 18,000（3.14%） |
| 总运行时间 | 约 14.9 小时 |
| 平均吞吐量 | 约 201 对/小时 |

由于每对要求 6 个响应全部可解析，3.14% 的单次解析失败被放大为 17.2% 的整对排除。主要失败模式是 Markdown 数字格式、缺少固定 evidence 标记以及输出在 192 token 处截断。

## 位置偏差

| 指标 | 结果 |
|---|---:|
| 第一位置平均分优势 | +0.5761 |
| 非平局方向样本的第一位置胜率 | 67.6% |
| AB/BA 聚合方向冲突 | 1,115 / 3,000（37.2%） |
| BPC 后清单 `image_a` 获胜率 | 49.7% |

BPC 消除了最终输出层面的整体方向失衡，但原始模型仍存在明显位置偏好。只能使用校准后的 winner，不能使用单一 AB 或 BA 方向。

## 排名

有效票覆盖全部 250 张图片。每图有效比较数为 13–23，中位数 19。Q-score 与 TrueSkill 的 Pearson 相关为 0.9849，Spearman 相关为 0.9886。

这些指标说明两个聚合器内部一致，但不等价于和人类判断一致。当前只有一个预先固定标签的 4 对微型检查（4/4 符合），不足以报告正式 human-alignment accuracy 或 kappa。

## 使用边界

本结果适合探索性 VP 排名和校准方法研究。若用于论文主结论，建议：

1. 对具有代表性的随机样本进行独立、盲法、位置随机的人类复标；
2. 报告准确率、Cohen/Fleiss kappa 和置信区间；
3. 对高 BPDE 图片对进行重点人工复核；
4. 在不改变提示词的前提下，通过解析兼容和缺失样本重试恢复格式无效对。
